Hỗ trợ đầy đủ macOS (Native MenuBar) và Windows / Linux standalone app

RECOMMENDED
🍏

macOS Native MenuBar App

Dành cho Apple Silicon (M1/M2/M3/M4) & Intel Mac (macOS 12.0 trở lên).

  • ✅ Tự động quét ~/.gemini/antigravity/brain nền hệ thống
  • ✅ MenuBar icon ghim góc phải màn hình, mở nhanh 1 click
  • ✅ Ghim Always On Top tiện vừa code vừa ngắm bot làm việc
  • ✅ Tự động Watchdog giải phóng các job agent bị treo
💾 Tải Bản .DMG Tốc Độ Cao (12 MB) 📦 Tải Bản .ZIP (12 MB)
Mở lần đầu (Gatekeeper Fix):
xattr -cr /Applications/AntigravityMonitor.app
🪟 🐧

Windows & Linux Desktop

Khởi chạy độc lập dưới dạng cửa sổ Desktop App không viền URL.

🪟 Windows (Edge App Mode 1-Liner):
Start-Process msedge.exe -ArgumentList "--app=file://$PWD/app.html", "--window-size=1200,800"
🐧 Linux (Chromium App Mode):
chromium --app="file://$(pwd)/app.html" --window-size=1200,800
🐍 Hoặc chạy qua Python Webview (Cực nhẹ):
pip install pywebview && python3 -c "import webview; webview.create_window('Antigravity Monitor', 'app.html', width=1200, height=800); webview.start()"
